# Power Query Projects

A collection of data-cleaning and data-preparation exercises built with **Power Query** (Excel / Power BI).
The repository documents my learning path towards a Data Analyst role.

## Contents

| Folder | What it contains |
|---|---|
| [`power-query-learning/`](power-query-learning/) | Learning notes and a practice dataset (`sales.csv`, 10,000 shoe-sales records from 2024). |
| [`superstore_dataset/`](superstore_dataset/) | Superstore sales workbook (`superstore_dataset.xlsx`, about 9,800 orders, 18 columns) used for transformation exercises. |

## Skills practised

- Importing CSV files with a custom delimiter and locale-aware dates
- Cleaning and typing columns, removing duplicates, handling errors
- Merging and shaping tables before analysis

## How to use

1. Download the dataset you want to work with.
2. In Excel or Power BI choose **Get Data**, then **From Text/CSV** (or **From Workbook** for the `.xlsx` file).
3. For `sales.csv` set the delimiter to semicolon and the date locale to Polish, see [`power-query-learning/dataset/README.md`](power-query-learning/dataset/README.md).
